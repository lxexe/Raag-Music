# Raag Music branding

Final spelling: **Raag Music**. The chosen rounded note was adapted from an AI-generated coral-and-cream concept and redrawn as native vectors. Only production assets are retained.

- Coral background: `#F05243`; warm cream foreground: `#FFF4DF`.
- [Editable icon](branding/raag-music-icon.svg), [PNG preview](branding/raag-music-icon.png), [transparent symbol](branding/raag-music-logo.svg).
- Android adaptive/themed layers: `app/src/main/res/drawable/brand_*`.
- Matching notification symbol: `ic_raag.xml`. Native resource and application class names use the Raag brand.
- Home uses lighter coral in dark themes and deeper coral in light themes.
